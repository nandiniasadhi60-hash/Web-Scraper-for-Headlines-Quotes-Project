
# Web Scraper for Headlines & Quotes

## Project Description
The Web Scraper for Headlines & Quotes is a Python-based project that automatically collects website headlines, interesting quotes, and author names using web scraping techniques.

It uses Requests and BeautifulSoup libraries to extract information from websites and stores the collected data in CSV files.

## Technologies Used
- Python
- Requests
- BeautifulSoup
- CSV
- Visual Studio Code

## Project Structure

WebScraper/
│
├── scraper.py
├── headlines.csv
├── quotes.csv
├── requirements.txt
└── README.md

## Features
- Automatically collects website headlines.
- Extracts interesting quotes.
- Collects author names.
- Stores data in CSV files.
- Displays collected information in the terminal.

## Installation

Step 1: Install Python.

Step 2: Install required libraries.

```bash
pip install -r requirements.txt
```

## How to Run the Project

Open the project folder in VS Code.

Open the terminal and execute:

```bash
python scraper.py
```

## Output Files
- headlines.csv – Stores collected headlines.
- quotes.csv – Stores collected quotes and authors.

## Applications
- Collecting website information.
- Learning web scraping techniques.
- Automating data collection.
- Basic data analysis.

## Conclusion
This project demonstrates how Python can be used to extract website information automatically and save it in CSV files for future use.
